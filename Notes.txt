History of java - Introduction
  1. 1991: Java was started as a project called "Green Project" at "Sun Microsystems"
  2. Founder: Java was developed by a team led by "James Gosling".
  3. Original Name: Java was initially named "Oak"
  4. Rason for Development:
    -> it was originally designed for electronic devices such as set-top boxes and other consumer electric devices.
  5. 1995: "Oak" was renamed "JAVA" and oficially introuduced to the public.
  6. Main Goal: Java introduced the concept of 
              "Write Once, Run Anywhere(WORA)"
    -> meaning the same "Compiled java program could run on different playforms with a compatable JVM"
  7. 1996: JDK 1.0 was oficially released.
  8. 2006: Sum Microsystems made much of Java's source code open source through the openJDK project.
  9. 2010: "Oracle acquired Sun Microsystems and become the owner of Java."
  10.2017: Java 9 introduced the Java Platform Module Sustem(JPMS).
  11.2018: Java adopted a "Six-month release cycle"
    -> meaning new feature versions are generally released twice a year.
  12.2021: Java 17 was released as an LTS(Long-Term Support) version.
  13.2023: Java 21 was released as an LTS version.
  14.2025: Java 25 was released as an LTS version.

JAVA DAILE USEFUL COMMANDS
=============================
1. JAVA version and Path 
  -> java --version                 - Displays the installed java version (JDK, JVM version) 
  -> javac --version                - Displays the installed java compiler version
  -> where.exe java                 - shows the path of java executable "java.exe" file in computer
  -> where.exe javac                - shows the path of java compiler "javac.exe" fild in computer
  -> echo %JAVA_HOME%               - shows the path configured in computer environmental variables.
2. JAVA Compilation and Execution
  -> javac Main.java                - Compile java file
  -> java Main                      - Run compiled java class
  -> java Main.java                 - Directly compile and run (java 11+)
  -> javac Main.java Hello.java     - Compiler more files.
  -> javac -d out Main.java         - compile into a output directory
  -> java -cp out Main              - Run using class path 
  -> java Main hello 123            - Run with arguments
3. Bytecode and class file inspection (javap - java class file disassembler , informally java profiler)
  -> javap Main                     - Display clas info.
  -> javap -v Main                  - Display detailed class structure
  -> javap -c Main                  - Display bytecode
  -> javap -p Main                  - Display private members
  -> javap -s Main                  - Display method descriptors(s -signature, like for int ->I(bytecode))
  -> Format-Hex .\Main.clas         - to inspect ras class file bytes(PowerShell);
  - example combined
    -> javap -v -c Main

WORKING OF JAVA -JDK, JRE and JVM
==================================
  -> when we write a java code, the computer cannot directly understnad the java code.
  -> so, java follows a process to convert our code into a format that the JVM can understand and execute.
  Process 
      java code(Main.java) 
              | 
      javac (Bytecode ie Main.class)
              | 
      JVM executes the Bytecode.
      - java compiler (javac )  converts java  source code into Bytecode.
      - Bytecode stored in .class file
      - Bytecode is playform independent, like the same Byte code can run  on differnt OS if a compatable JVM is available.

  1. JVM (Java Virtual Machine) 
    - JVM is an abstract Virtual machine that provides run time evnironment to load, verify, and execute Java Bytecode(.class file).
      It act as a bridge between Java Bytecode and the operating system.
      -> JVM is Platform dependent because each OS needs a compatable JVM.
      -> JVM starts execution from the "main()" method of the specified main class.
      -> JVM loads other required classes whenever needed, Does not execute every class file at once.
      -> The "main()" method is "static", so JVM can invoke it without creating an object.

  2. JRE (Java Runtime Environment) - JVM + JAVA Class Libraries + Supporting Runtime Files.
    - JRE is a software evnironment that provides all the necessary components to run java applications,
      including JVM, Java class libraries, and supporting runtime files.
      -> JVM alone is not sufficient to run java applications
        - it needs Java libraries and supporting files.
          ex: Sustem    -Predefined Java class
              out       -Predefined output stream
              println() -Predefined method
      -> JRE contains JVM, Java class libraries, and supporting files.
      -> JVM executes Java Bytecode (.class file).
      -> Java class libraries provide Predefined classes, methods, and functionalities.

  3. JDK(Jaca Development Kit)             
    - JDK is a software Development kit that provides the tools required
      develop(write), compile, debug, and run java applications.
      ->it includes
        -> 'javac' compiler to convert '.java' files into '.class' files.
        -> 'javadoc' to generate Java documentation.
        -> debugging tools to identify and fix errors.
        -> other tools required for java Development.

    - JDK = Development tools  +  Runtime components
        -> Development tools (javac, jar, jshell, javap,javadoc, jdb)
        -> Runtime components (JVM, Java class libraries, Supporting Runtime Files.)
